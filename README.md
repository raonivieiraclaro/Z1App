# Z1 Prospect IA

Protótipo de painel web da Zyone Cosméticos. Inclui demonstração de consulta ao catálogo e links configuráveis. **Não realiza prospecção nem mensagens automáticas.**

## Render
Use **New > Blueprint** no Render, conecte este repositório e configure `Z1_ADMIN_USER` e `Z1_ADMIN_PASSWORD` como segredos. O banco gratuito é efêmero: não insira leads ou tokens reais.

## Android
O workflow `Android APK` será adicionado após validação do projeto Android. Consulte o pacote fonte entregue anteriormente.
